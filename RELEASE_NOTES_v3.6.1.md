## 🎥 Universal YouTube Stream Resolution & Anti-Throttling Engine

Resolves the `"unable to resolve stream"` error and stream loading failures when downloading YouTube video or audio:

### 1. Device-Native Chunk Streaming via CapacitorHttp
- **Google Video IP Binding**: YouTube InnerTube stream URLs contain an encrypted `&ip=<resolving_ip>` parameter. When URLs are resolved on-device in the Android APK, only the phone's native IP is authorized by Google edge servers to fetch stream chunks.
- **Universal Chunk Fetcher (`fetchChunkUniversal`)**: Range-chunk fetching on Android APK now routes through `CapacitorHttp.request({ responseType: "arraybuffer" })`, executing directly through the native Android OkHttp stack. This bypasses browser CORS limitations and guarantees that outgoing requests originate from the exact IP authorized for the stream URL.
- **Web Proxy Fallback**: On Web deployments, requests route through `/api/youtube/stream` with strict `Cross-Origin-Resource-Policy: cross-origin` headers.

### 2. Multi-Candidate Edge Node Failover (`mn` Extraction)
- Stream URLs from InnerTube often route to primary edge nodes (`sn-4pgnuapo3jvh-cpgl`) that can be throttled or unresponsive on certain mobile carriers and local ISPs.
- The engine now automatically parses secondary candidate nodes from the URL's `mn` parameter (e.g. `sn-fapo3ox25a-3uh6`) and tests responsive chunk probe connectivity. If the primary node times out or fails with 403, the engine seamlessly fails over to the responsive secondary node.

### 3. iOS Client User-Agent Alignment
- When streaming formats generated by YouTube's iOS InnerTube client (`c=IOS`), the stream proxy dynamically forwards the matching iOS mobile User-Agent (`com.google.ios.youtube/20.10.4...`), eliminating header mismatch rejection from Google Video servers.

### 4. Next.js Route Normalization & Trailing Slash Redirection Fix
- Standardized API route construction in `innertube.ts` to prevent trailing slash appending (`/api/youtube/stream/?url=...`), eliminating HTTP 308 redirects that previously stripped `Range` headers during chunk requests.

### 5. SharedArrayBuffer Multithreading with COEP `credentialless`
- Upgraded `Cross-Origin-Embedder-Policy` from `require-corp` to `credentialless` in `next.config.ts`. This preserves full multi-core WebAssembly multithreading via `SharedArrayBuffer` while allowing unblocked streaming of external media without CORS/CORP aborts.

## 📐 Universal Phone Layout & Cutout Architecture

Fixes layout breaking, card overflows, and notch displacement across all phone form factors (compact screens <360px, tall phones, foldables, and tablets):

- **Safe-Area Notch Normalization**: Removed duplicate `pt-[env(safe-area-inset-top)]` and `pb-[env(safe-area-inset-bottom)]` styling from the root `body`, consolidating safe-area offsets to the persistent `TopBar` component and eliminating double-padding on notched devices.
- **Android Display Cutout Configuration**: Implemented `shortEdges` window layout in `values-v28` and `values-v31` styles (`android:windowLayoutInDisplayCutoutMode`), allowing edge-to-edge rendering without intrusive black bars around camera cutouts.
- **Downloader Card Adaptability**:
  - URL input box features responsive padding and scalable text sizing (`text-xs sm:text-sm`).
  - "FETCH VIDEO" action button stretches to full-width on mobile viewports (`w-full sm:w-auto`).

  - Action buttons ("START TURBO DOWNLOAD", "EXTRACT AUDIO") incorporate responsive truncation to prevent label wrapping on compact screens.

## 🏎️ 120Hz Hardware Kinetic Momentum & Touch Scrolling Engine

Completely resolved the Android APK touch scrolling freeze:

- **Root Viewport Delegation**: Updated `html` and `body` CSS in `globals.css` so that scrolling is delegated cleanly to the root viewport (`html { overflow-x: clip; scroll-behavior: smooth; }`, `body { overflow-y: visible; touch-action: pan-y pinch-zoom; -webkit-overflow-scrolling: touch; }`).
- **Eliminated WebView Scroll Trapping**: Removed internal `overflow-y: auto` containment on `body` that prevented Chromium WebView from passing touch gestures to Android's `NestedScrollingChild` gesture detector.
- **Buttery 120Hz Flings**: Enables full hardware-accelerated kinetic momentum and touch flings across high-refresh-rate displays without requiring drag-only touch interactions.
